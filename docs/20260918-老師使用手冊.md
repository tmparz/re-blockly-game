# Blocky Easy 老師使用手冊

這份說明是給帶課老師使用的。照下面順序操作即可，不需要先懂程式或專案設定。

## 上課前 30 秒

1. 用 iPad 或電腦開啟 <https://tmparz.github.io/re-blockly-game/>。
2. 要上自製闖關課程，就留在首頁；要玩 Google Blockly Games 六個教學遊戲，點「Blockly Games 觸控版」。
3. iPad 建議橫向使用，畫面較寬，拖拉積木比較容易。
4. 先讓學生做一關；卡住時先按「提示」，老師需要示範時再按「示範」。

## 要選哪一套？

### Blocky Easy

適合完整帶課。共有 100 關，從移動、Repeat、For、While、If 到綜合挑戰，老師可以依程度選關卡。

### Blockly Games 觸控版

適合延伸活動。包含 Bird、Turtle、Movie、Music、Pond Tutor、Pond。數字、角度與音符欄位已加入大型觸控輸入，方便 iPad 使用。

## Blocky Easy 常用按鈕

| 按鈕 | 用法 |
| --- | --- |
| 執行 | 跑目前排好的積木，觀察結果。 |
| 回到起點 | 角色回到本關起點，積木保留。 |
| 重來 | 清掉目前程式，重新排積木。 |
| 提示 | 給學生方向，不直接公布完整答案。 |
| 示範 | 放入參考積木，適合老師講解或最後對答案。 |
| 下一關 | 完成本關後往下一題。 |

## iPad 操作重點

- 拖拉積木時，用手指按住積木再移動。
- Bird、Movie、Music、Pond 等頁面遇到數字、角度或音符欄位，點欄位後會出現大型觸控選擇器。
- 輸入完成後按「確定 / Apply」才會套用；按「取消 / Cancel」會保留原值。
- 畫面太擠時，先改成橫向再重新整理。

## 學生卡住時

### 首頁出現「Blockly 沒有載入」

Blocky Easy 首頁目前會從 `unpkg.com` 載入 Blockly，所以教室網路需能連外。先確認網路，再重新整理頁面。

### iPad 點數字卻不能輸入

確認學生進入的是本站的「Blockly Games 觸控版」。觸控版會跳出大型數字、角度或音符選擇器，不依賴 iPad 系統數字鍵盤。

### 一直過不了關

先看「方塊數限制」與「提示」。部分關卡刻意要求使用 Repeat、For、While 或 If，堆很多前進積木不一定能通過。

## 老師上課可以照這個節奏

1. 示範一關，只講「拖積木 → 執行 → 看結果」。
2. 讓學生自己做 2～3 關，老師先只回答操作問題。
3. 出現 Repeat／For 後，請學生先說出「哪一段一直重複」。
4. 進入 While／If 後，先用中文說規則，再去排積木。
5. 最後用「示範」對答案，請學生比較自己的做法與參考解法。
