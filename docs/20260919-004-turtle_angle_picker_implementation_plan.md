# 烏龜關卡轉彎角度圓盤選擇器實作計畫書

## 需求背景與目標
在目前 Blockly Games 的「烏龜（Turtle）」關卡中：
- 關卡 1 至 9：轉彎積木（`turtle_turn_internal`，向左轉 / 向右轉）使用的是靜態下拉選單（`field_dropdown`），僅提供死板的 6 個選項（`1°`、`45°`、`72°`、`90°`、`120°`、`144°`），使用者無法直觀旋轉方位。
- 關卡 10（自由畫廊）：轉彎積木（`turtle_turn`）使用數字輸入積木（`math_number`），點擊時會被前次的觸控修補腳本攔截為全螢幕數字鍵盤，無法看到旋轉角度。

**使用者目標**：
將烏龜關卡在轉彎（向左轉 / 向右轉）時的角度選擇方式，改成與「鳥（Bird）」關卡一樣的**圓形方位盤（Circle Dial Angle Picker）**，讓學童與使用者能直接點擊、旋轉指針來設定轉向角度。

## 關鍵技術難點與防禦性架構設計

### 1. 烏龜關卡特殊角度與吸附問題（關鍵發現）
- **問題**：鳥關卡（Bird）的方向均為 15° 或 45° 的倍數（0, 45, 90, 135, 180, 225, 270, 315），預設每 15° 吸附一格（`rj = 15`）。
- **衝突**：烏龜關卡的核心幾何題目需要：
  - 第 2 關（正五邊形）：外角為 **72°**（非 15 的倍數）
  - 第 3、4、5、6、7 關（五角星）：外角為 **144°**（非 15 的倍數）
  - 第 8、9 關（圓形／月亮）：轉角為 **1°**（非 15 的倍數）
- **風險**：若直接生硬套用 15° 步進圓盤，使用者在圓盤上旋轉將**永遠選不到 72°、144°、1°**，導致關卡直接卡死無法通關！
- **專業解決方案**：
  1. **圓盤本體**：外觀與互動同鳥關卡一致（SVG 圓形盤、刻度線、紅色指針、旋轉扇形）。
  2. **智慧步進與自由微調**：步進設為 1° 或提供平滑拖曳，指針能指向任何整數角度。
  3. **整合常用角度快捷按鈕列**：在圓盤下方加入烏龜常用的角度按鈕：
     `[ 1° ] [ 45° ] [ 72° ] [ 90° ] [ 120° ] [ 144° ]`
     點擊按鈕時，指針與扇形瞬間動態旋轉至該角度，積木同步更新數值。
  4. **頂部數字輸入框**：保留直接文字鍵盤打字輸入，多重操作路徑確保 100% 友善與可用性。

### 2. 避免 Touch Keypad 攔截衝突
- 目前 `scripts/patch-blockly-games.mjs` 中將 `Sn.prototype.Qd`（`FieldTextInput.prototype.showEditor_`）攔截為 `BlocklyTouchInput.open(...)` 數字鍵盤。
- `FieldAngle` 繼承自 `FieldTextInput`，若未做分流判定，點擊角度時會被數字鍵盤強制劫持。
- **解法**：在 `Sn.prototype.Qd` 加入 `if (this instanceof FieldAngle) { ... return; }` 分流，角度專門彈出圓盤，一般數字才走觸控數字鍵盤。

## 驗證計畫

### 1. 語法與建置驗證
- 執行 `node --check blockly-games/turtle/generated/compressed.js`
- 執行 `node --check scripts/patch-blockly-games.mjs`
- 執行 `npm run check`（確保程式碼風格、行數與關卡檢驗均通過）
- 執行 `npm run build`

### 2. 瀏覽器互動與關卡驗證
- 開啟 `blockly-games/turtle.html`：
  - **關卡 1（正方形，90°）**：點擊轉彎積木的角度，驗證彈出圓盤指針，旋轉或點選 90°，執行並確認過關。
  - **關卡 2（五邊形，72°）**：點擊轉彎積木，透過圓盤或常用按鈕選取 72°，指針即時旋轉至 72°，執行確認五邊形繪製成功。
  - **關卡 3（五角星，144°）**：點擊轉彎積木，選取 144°，驗證五角星正確繪製並過關。
  - **關卡 8（滿月，1°）**：點擊轉彎積木，選取 1°，驗證 360 次迴圈畫出滿月。
  - **關卡 10（畫廊）**：驗證轉彎積木亦支援圓盤角度調整。
