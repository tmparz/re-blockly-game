# 高複雜度 Advanced For 關卡擴充設計與評估報告 (續)

本文件詳述基於第 39 關（蛇形管道 `adv-for-serpentine-pipe`）的極致複雜度模型，所全新設計並寫入系統的兩個超高難度視覺化積木關卡：「三峰山脈巡檢」與「核心電路板」。

---

## 1. 關卡核心設計說明

新增的兩大關卡，其邏輯深度、嵌套迴圈架構以及方塊目標數（14 ~ 17 個方塊）與「蛇形管道」同級，甚至在幾何軌跡與轉向多維度上更具挑戰性。

### 第一關：三峰山脈巡檢 (Three Peaks Mountain)
*   **關卡 ID**：`adv-for-three-peaks`
*   **地圖網格**：`9x7`，起點於左下角 `{ x: 0, y: 5 }`，終點於右下角 `{ x: 8, y: 5 }`。
*   **設計概念**：**階梯式波形對稱巡迴**。玩家需要越過兩座階梯山峰，每座山峰的頂峰 `{ x: 2/6, y: 2 }` 與谷底 `{ x: 4/8, y: 5 }` 各置有一顆能量石。
*   **邏輯深度與方塊配置 (Target: 17 Blocks)**：
    - 上山階梯與下山階梯本身均需使用 For 迴圈重複 2 次。
    - 在頂峰與谷底分別執行：前進 1 步、收集、轉身 180 度。
    - 外層 For 迴圈將整套「上山 -> 頂峰採集 -> 下山 -> 谷底採集」重複 2 次。
    - 這需要極強的空間想像力，將縱向與橫向階梯以嵌套迴圈簡雅地解決。

### 第二關：核心電路板 (Integrated Circuit S-Track)
*   **關卡 ID**：`adv-for-circuit-board`
*   **地圖網格**：`8x8`，起點於左下角 `{ x: 0, y: 7 }`，終點於右下角 `{ x: 6, y: 7 }`。
*   **設計概念**：**雙重縱向 S 型軌跡與焊接點採集**。玩家需要在曲折的電路板軌跡中，在所有的縱向折返點（頂部與底部共 4 個焊接點）採集能量點。
*   **邏輯深度與方塊配置 (Target: 14 Blocks)**：
    - 外層 For 重複 2 次。
    - 每一輪包含：前進 3 步（縱向長管）、收集、右轉、前進 2 步（水平短管）、右轉、前進 3 步、收集、左轉、前進 2 步、左轉。
    - 此設計高度對稱，將縱向步數（3 步）與水平步數（2 步）完美嵌套，極大考驗玩家對迴圈代碼塊重用性的極限理解。

## 2. 全方位專業評估與專案管理分析 (Rule 5)

本專案新增的高難度關卡是基於專業軟體工程原則所進行的擴充，其詳細指標評估如下：

| 評估面向 | 評估結果與工程分析 |
| :--- | :--- |
| **商業與教育價值** | **極高**。高難度的關卡能有效延長學習較快學生的挑戰性與趣味性，避免其提早失去耐性。同時，高度對稱的幾何結構本身具備數學上的對稱美，能培養優美的程式審美觀。 |
| **技術可行性** | **完美可行**。此擴充沿用 Blocky Easy 已臻成熟的座標與地圖物件模型，不涉及任何編譯或底層 API 變更，維持了純靜態前端架構的穩健性。 |
| **開發成本** | **極低**。採用宣告式配置，開發工時僅需數小時，且與渲染引擎邏輯完全解耦。 |
| **維護成本** | **極低**。未來若需調整地圖障礙，只需修改 `app.js` 的宣告式陣列，無邏輯維護負擔。 |
| **資安風險** | **零風險**。純客戶端網頁沙盒執行，無任何後端注入或 XSS 暴露面。 |
| **擴充性** | **優異**。關卡在 `LEVELS` 陣列中呈鬆耦合排列，隨時可以熱插拔、調換順序或單獨移入 `levels.json`。 |

| **上線風險** | **極低**。已在本地進行 `npm run build` 編譯，無任何 JS 語法錯誤，部署隨插即用。 |
