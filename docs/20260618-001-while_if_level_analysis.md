## 二、新增 4 關 WHILE 高難度關卡

### W1: While：走停收集混合迴圈 (while-for-mixed-patrol)
- **概念**: While + For 混合
- **難度**: ★★★★★
- **核心**: 外層 While 走到底後，用 For 重複固定步數做收集模式
- **覆蓋缺口**: 首次在 WHILE 階段混合使用 For 重複

### W2: While：三層深井探測 (while-triple-nested-scan)
- **概念**: 三層巢狀 While
- **難度**: ★★★★★
- **核心**: While(NOT_DONE) > While(FRONT_CLEAR) > While(ON_GEM)
- **覆蓋缺口**: 首次出現三層巢狀結構

### W3: While：多條件交叉巡檢 (while-multi-condition-cross)
- **概念**: While + 多條件交叉
- **難度**: ★★★★★
- **核心**: 同一迴圈體中同時使用 FRONT_BLOCKED + ON_GEM + move_forward
- **覆蓋缺口**: 首次在單一迴圈內交叉運用三種不同 While 條件

### W4: While：雙死巷分支回程 (while-dual-deadend-branch)
- **概念**: While + 回程 + 分支
- **難度**: ★★★★★
- **核心**: 從中間出發進入死巷收集、轉身回程、再換方向進另一死巷
- **覆蓋缺口**: 首次要求多方向死巷探索與回程
