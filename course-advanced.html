第三階段課程：Code Inventors 💡

給完成第二階段（Code Builders）的學生，適合國小四年級或進度快的三年級。學生已經會除錯、寫函式、用一個計數器、用事件做出產品；這一階段把每個觀念「升級」：函式可以帶輸入、條件可以比大小、變數可以有兩個、程式可以有隨機，還要學會比較哪個演算法比較好，最後做出一個完整的遊戲。

1. 從第二階段升級什麼？

🧩 → 🎛️ 函式

以前「跳兩格」只能走 2 格。現在函式可以帶一個輸入（參數）：「走 3」、「走 5」都用同一個函式。

❓ → ⚖️ 條件

以前只能問「前面有路嗎？」「分數 = 5 嗎？」。現在可以比大小：計數器 > 3、< 2，以及兩個條件一起判斷。

🔢 → 🎒 變數

以前只有一個計數器。現在 Robo 有兩個變數（寶石和電池），要想清楚每個方塊在改哪一個。

🎬 → 🎲 產品

以前的產品每次都一樣。加上隨機、計時和生命值，做出每次玩都不一樣的遊戲。

2. 12 週總覽

週單元／活動主要內容狀態
第 1 週🎛️ Function Inputs 1–6不插電「點餐機」：同一道菜，客人說幾份就做幾份。輸入是送進函式的數字；同一個函式送不同數字；修正數字；自己寫「重複 輸入 次」。✅ 可以上課
第 2 週🎛️ Function Inputs 7–12漩渦裡的數字規律、右轉 3 次 = 左轉、轉角函式、把計數器當輸入（越來越大的漩渦）、魔王關。✅ 可以上課
第 3 週⚖️ Compare & Decide 1–6大於、小於、等於；「計數器 > 3 才開門」；用比較讓迴圈停下來。🚧 開發中
第 4 週⚖️ Compare & Decide 7–12如果裡面再放如果（巢狀判斷）、兩個條件一起判斷（而且／或者）、找出邊界的 bug（> 還是 ≥）。🚧 開發中
第 5 週🎒 Two Variables 1–6不插電「兩個盒子」；寶石和步數同時數；說出指定的那一個；放錯盒子的 bug。🚧 開發中
第 6 週🎒 Two Variables 7–12電池用完就停、用一個變數決定另一個、兩個變數 + 參數的魔王關。🚧 開發中
第 7 週🎲 Random & Game Rules 1–4Story Lab：隨機數字、每次玩都不一樣、計時器變數。🚧 開發中
第 8 週🎲 Random & Game Rules 5–8生命值、遊戲結束畫面、難度慢慢變高、做出一個完整的小遊戲。🚧 開發中
第 9 週🧪 Algorithm Race 演算法比賽兩個程式都能過關，哪個比較好？比較方塊數和步數；用追蹤表算出 Robo 走了幾步。🚧 開發中
第 10 週🚀 期末專題：遊戲企劃寫遊戲規則（怎麼贏、怎麼輸、分數、時間）、畫畫面、列出 v0.1 到 v1.0 的功能。🚧 開發中
第 11 週🚀 期末專題：製作、試玩、改編兩人一組製作；交換試玩並改編同學的遊戲，標示原作者。🚧 開發中
第 12 週🚀 遊戲發表會上台展示：用了哪些變數、哪裡用了參數和比較、試玩後改了什麼。🚧 開發中

3. 單元細節

🎛️

單元 1：Function Inputs 函式參數（第 1–2 週，12 關）

函式可以帶一個數字輸入。「執行 走 輸入 🎛️ 3」會把 3 送進去，函式裡的「重複 🎛️ 輸入 次」就重複 3 次。1–4 🟢 簡單、5–8 🟡 中等、9–12 🔴 困難。

開始 ➜

學習目標

  • I can send a number into a function (an input).
  • I can use one function for many jobs by changing the input.
  • I can write a function that uses its input.
  • I can send a variable as the input.

關鍵字

inputparameterargumentpatterngeneralize

不插電暖身

「點餐機」：一位學生當廚師，只會一道菜的做法（函式）。客人喊「2 份！」「5 份！」，廚師照同一個做法做不同份數。問：做法要改嗎？改的是什麼？

重點觀念

  • 第 3 關：函式沒錯、是數字錯，學會分辨「改輸入」和「改函式」。
  • 第 4 關：一個有輸入的函式，取代以前的「跳兩格」和「衝三格」。
  • 第 8 關：右轉 3 次 = 左轉，輸入不只能用在走路。
  • 第 11 關：把計數器當輸入，接回第二階段的變數。
  • 第 12 關：大小不同的兩個漩渦，用「重複 5 次」會撞牆，要用「重複直到 🏁」。
⚖️

單元 2：Compare & Decide 比較與判斷（第 3–4 週，規劃中）

條件可以比大小：計數器 >、<、= 某個數字；巢狀判斷；兩個條件一起判斷。

學習目標

  • I can compare two numbers with >, < and =.
  • I can put an if inside another if.
  • I can find a bug at the edge (> or ≥).

不插電暖身

「身高門」：比 120 公分高才能玩。剛好 120 可以嗎？引出 > 和 ≥ 的差別。

🎒

單元 3：Two Variables 兩個變數（第 5–6 週，規劃中）

Robo 同時有「寶石」和「電池」兩個變數；每個方塊都要選它改的是哪一個。

學習目標

  • I can use two variables for two different things.
  • I can choose which variable a block changes.
  • I can use one variable to decide what happens to another.

不插電暖身

兩個紙盒，一個裝寶石卡、一個裝電池卡。老師唸指令，學生把卡放進正確的盒子。

🎲

單元 4：Random & Game Rules 隨機與遊戲規則（第 7–8 週，規劃中）

在 Story Lab 加入隨機數字、計時器和生命值，做出每次玩都不一樣的遊戲。

學習目標

  • I can use random numbers to make a game different every time.
  • I can use a timer and lives to decide when the game ends.
🧪

單元 5：Algorithm Race 演算法比賽（第 9 週，規劃中）

兩個程式都能過關，比一比誰的方塊少、誰走的步數少，並說明理由。

學習目標

  • I can compare two algorithms that solve the same problem.
  • I can explain why one is better (fewer blocks or fewer steps).
🚀

單元 6：期末專題「我的遊戲」（第 10–12 週，規劃中）

企劃 → 製作 → 交換試玩 → 改編並標示原作者 → 發表。

評量規準（每項 1–3 分）

  • 變數：至少兩個變數，各有清楚的用途。
  • 規則：用比較決定輸贏。
  • 隨機：每次玩都有一點不一樣。
  • 迭代：試玩後至少改了一個地方，並說明原因。
  • 標示出處：改編別人的作品時寫出原作者。
